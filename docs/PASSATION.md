## Méthode d'une vague de travail

1. Lire ce fichier + CLAUDE.md avant de coder.
2. `bash scripts/verifier_invariants.sh` avant tout push — obligatoire.
3. Ne jamais éditer les pages générées (`/o/`, `/guides/`) à la main — éditer le gabarit dans `scripts/generer_pages_objets.mjs` puis régénérer (`--force`).
4. Bumper `sw.js` (wf-hub-vXXX) à chaque changement qui touche une page du cache SHELL (index.html, etc.) — sinon les visiteurs gardent l'ancienne version en cache indéfiniment.
5. Une PR par sujet, vérifiée avant fusion (pas seulement lue).
6. Mettre à jour ce fichier (section "Où on en est") après toute vague de travail.
